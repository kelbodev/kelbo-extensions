## [1.0.0] - 2026-11-09

### Added
- **Kelbo Light** (Kelbo 2.26): a light theme for the whole interface — shell, built-in and official extensions, command output, code highlighting, diffs, the commit graph and the notes — with darker extension colors that read well on white. Pick it from the theme button in the header, or let Kelbo follow the system light/dark setting. Requires Kelbo 2.26 or later.
