## [1.0.0] - 2026-11-09

### Added
- **Kelbo Dim** (Kelbo 2.26): a softer dark theme for the whole interface — slate grey instead of near-black, with less saturated colors for command output, code highlighting, diffs, the commit graph and the notes. Pick it from the theme button in the header, or let Kelbo follow the system light/dark setting. Requires Kelbo 2.26 or later.
